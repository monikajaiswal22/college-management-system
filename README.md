# 🏫 College Management System

**Live Demo:** [https://college-management-system-g3z2.onrender.com](https://college-management-system-g3z2.onrender.com)

**GitHub Repository:** [https://github.com/monikajaiswal22/college-management-system](https://github.com/monikajaiswal22/college-management-system)

A full-featured college management web application with Admin, Teacher, and Student portals.

## Features
- **Admin Dashboard:** Real-time charts for attendance, fees, and student stats.
- **Student Management:** Full CRUD operations with photo upload.
- **Attendance & Marks:** Subject-wise tracking and grade management.
- **Fee System:** Record fees, send email reminders, and generate PDF receipts.
- **User Roles:** Separate login portals for Admin, Teacher, and Students.
- **Public Website:** University homepage with notices and course info.

## Tech Stack
- **Backend:** Python, Flask
- **Database:** SQLite
- **Frontend:** Bootstrap, Chart.js, HTML/CSS
- **Deployment:** Render.com
